==================================================
BACKGROUND DESIGN DIRECTION
==================================================

Use a soft warm light-grey / off-white base instead of pure white.

The background should feel slightly richer and more designed.

Add multiple VERY SUBTLE visual elements:

1. MICRO GRID / BLUEPRINT GRID
- extremely thin lines
- very low opacity
- only visible when you look closely
- should not feel like graph paper

2. SOFT BLUE RADIAL GLOW
- use the existing website blue/accent tone
- very soft and blurred
- place mainly around the hero or selected empty areas
- opacity should be low
- should feel atmospheric, not like a gradient background

3. SMALL DESIGN MARKERS
Add occasional tiny:
- plus signs
- crosshair marks
- alignment markers
- corner marks

These should appear only in a few places.

Do NOT repeat them everywhere.

They should feel like subtle UI/design-system references.

4. LARGE OUTLINE SHAPES
In some empty background areas, add very large low-opacity:
- circles
- arcs
- partial rings

They should be barely visible.

Do NOT place them over important text.

5. SECTION GUIDE LINES
Use very subtle horizontal/vertical guide lines between some major sections.

They should help the page feel structured and editorial.
