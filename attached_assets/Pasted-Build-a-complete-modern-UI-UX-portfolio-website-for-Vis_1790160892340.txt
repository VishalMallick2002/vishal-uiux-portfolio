DO NOT CROP UI SCREENS INCORRECTLY
==================================================

Project screenshots are UI/UX work.

Their design must remain visible.

For case-study images:

Preserve the ORIGINAL ASPECT RATIO by default.

Do NOT blindly use:

for every project image.

Use:

or natural image dimensions for project content where appropriate.

Cover images on the homepage may use cover cropping intentionally.

But images INSIDE a case study should normally display the complete artwork.

No important parts of:
- mobile screens
- user flows
- wireframes
- dashboards
- mockups

should accidentally be cut off.
